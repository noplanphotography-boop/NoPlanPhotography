# Photo shoots

Android app for showing photo shoots to customers. Photos are stored on the phone.

## Get the APK
Every push runs the **Build APK** workflow. Open the latest run under the **Actions** tab
and download the `photo-shoots-apk` artifact, then install `app-debug.apk` on your phone
(allow installs from unknown sources when Android asks).

## Use
1. New photo shoot → upload all pictures → tap the ones to make main → Make main.
2. Open a main picture → tap unsorted pictures that belong to it → Add to this pose.
3. Shoot screen → Display mode. Press and hold the top-left corner for 1.5 s to leave.
